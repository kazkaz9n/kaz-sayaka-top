# KAZ & SAYAKA Top Page

This repository contains the official static top page for `KAZ & SAYAKA`.

## Official entry

- `index.html`: official public page

## Other files

- `editorial.html`: alternate concept page for comparison
- `about-kaz.html`, `about-sayaka.html`, `about-solunode.html`: draft reference pages
- `assets/`: images and icons used by the site

## Recommended GitHub Pages setup

1. Create a new GitHub repository.
2. Upload all files in this folder.
3. In GitHub, open:
   `Settings` -> `Pages`
4. Set:
   `Build and deployment` -> `Source` -> `Deploy from a branch`
5. Select:
   `main` branch and `/ (root)`
6. Save and wait for the site to publish.

The initial public URL will look like:

`https://your-account.github.io/your-repository-name/`

## Custom domain later

After confirming the site works on GitHub Pages, you can connect a custom domain from your domain registrar.

## Notes

- This is a static site, so no server setup is required.
- `.nojekyll` is included so GitHub Pages serves the files as-is.
